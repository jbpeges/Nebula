# Expedició Nèbula

Web educativa gamificada per treballar programació amb Micro:bit i Cutebot a Primària.

## Estat
Primera versió funcional: entrada d'equip, mapa de 4 missions, desbloqueig seqüencial, validació i progrés local.

## Seguretat
No s'hi han d'emmagatzemar contrasenyes reals al JavaScript del navegador. El codi provisional de validació s'ha de substituir per un sistema segur abans d'utilitzar-lo amb alumnat.
